# 🚀 NEBULA SPACE

**NEBULA SPACE**, 1998 yapımı kült klasik *Swarm* oyunundan esinlenen, saf HTML5 Canvas ve Web Audio API ile geliştirilmiş, 40 bölümlük taktiksel bir retro-arcade uzay it dalaşı oyunudur.

Harici hiçbir kütüphane veya oyun motoru bağımlılığı yoktur (Zero-dependency Vanilla JS).

---

## 🎮 Temel Özellikler

* **4 Farklı Gemi Modeli (Hangar Sistemi):**
  * ⚡ **VIPER:** Dengeli ve çevik önleme avcısı.
  * 🛡️ **TITAN:** Ağır zırhlı, 4 egzozlu yüksek dayanıklılıklı kruvazör.
  * 🔮 **PHANTOM:** Ters kanatlı, hipersonik stealth korvet.
  * 🔥 **PHOENIX:** Hızlı kalkan yenilemeli çift gövdeli katamaran taarruz gemisi.
* **7 Aşamalı Silah Cephaneliği (4 Seviye Evrim):**
  1. *Plazma Çift Namlu* (Sınırsız Temel Silah)
  2. *İkili Ağır Lazer* (Delici Yüksek Hız)
  3. *Güdümlü Kuantum Füze* (Isı Güdümlü Akıllı Mühimmat)
  4. *Nova Saçılma Topu* (Flak / Shotgun Yakın Savunma)
  5. *Takyon Ray Silahı* (Zırh Delici Hipersonik Işın)
  6. *Tesla Ark Topu* (Düşmanlar Arası Sıçrayan Şimşek Ağı)
  7. *Kuantum Vorteks* (Kara Delik / Çekimsel Tekillik Bombası)
* **Taktiksel Alan Mayınları (Sağ Tık):**
  * *Termonükleer Mayın:* Devasa patlama yarıçapı ile tüm filoları tek seferde buharlaştırır.
  * *EMP Şok Mayını:* Geniş alanda elektrik şoku dalgası yayar.
* **Akıllı İkmal Sistemi:**
  * Bölüm başlangıcında haritaya yerleştirilmiş stratejik ikmal kutuları.
  * Yok edilen düşmanlardan düşen ganimetler.
  * 280m yaklaşınca gemiye kilitlenen **Manyetik Çekim Işını (Tractor Beam)**.
* **40 Kademeli Harekât:**
  * Bölüm geçtikçe artan düşman filoları: Avcılar, Harvester'lar, Kruvazörler ve Kıvrak Ölüm Solucanları.
  * Her bölüm sonunda detaylı skor ve durum analizi.
* **Gelişmiş HUD & Radar:** 3000m menzilli taktiksel sektör radarı, anlık kalkan/gövde telemetrisi ve duraklatma (ESC) sistemi.

## 🕹️ Kontroller

| Eylem | Kontrol |
| :--- | :--- |
| **Gemi Yönü** | Fare İmleci |
| **İtici (Motor)** | `SPACE` veya `W` |
| **Seri Ateş** | Farenin Sol Tıkı |
| **Alan Mayını Bırak** | Farenin Sağ Tıkı |
| **Mayın Değiştir** | `Q` / `E` Tuşları |
| **Silah Seçimi** | `1` - `7` Tuşları veya Fare Tekerleği |
| **Oyunu Duraklat** | `ESC` Tuşu veya `⏸️` Butonu |

## ⚡ Kurulum ve Çalıştırma

Herhangi bir sunucu kurulumu gerektirmez:
1. Projeyi indirin veya klonlayın.
2. `index.html` dosyasına çift tıklayarak herhangi bir modern tarayıcıda (Chrome, Edge, Firefox, Safari) doğrudan oynayın.
3. Vercel veya GitHub Pages üzerinde sıfır konfigürasyon ile doğrudan yayına alınabilir.
